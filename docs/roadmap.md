# Roadmap

## Phase 1: MVP

- JSON fallback object repository.
- Cesium entity rendering.
- Layer panel, property panel, attribute table.
- Picking, highlighting, camera tools, measurement, and simple slicing.

## Phase 2: Data and Scale

- PostGIS repository implementation.
- OSM and Overture ingestion.
- glTF and 3D Tiles cache generation.
- Spatial indexes using HybridBox fields.

## Phase 3: GUGIS Operations

- BooleanStructure union, difference, and intersection services.
- Template editing and procedural geometry expansion.
- Query acceleration by HybridBox / BallBox.

## Phase 4: AI Integration

- AI result layer for object extraction outputs.
- Confidence, provenance, and human correction workflow.
- Import point-cloud segmentation outputs as object candidates.

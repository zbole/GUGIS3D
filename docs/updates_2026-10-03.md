# 更新说明 · 2026-10-03

本次合并 DOT 的八次开发提交（`6ae5c9a` → `2907810`），并在 Windows 本地完成恢复、启动和交互验收。

## 主要更新

- **建筑显示与查询：**修复空 `overview` 导致精细建筑消失的问题；密集城区保留所点对象详情；联合剖面使用真实构件包络筛选，避免偏小简模造成漏选。
- **历史记录与剖面重试：**历史列表支持刷新、原页重试和分页；路线变化时取消失效 Worker；剖面失败后可保留原路线重新计算。
- **对比证据校对：**返回对比页时自动检查最新城市修订号，支持手动校对和失败重试；明确提示当前、过期或无法校对的状态，不替换已保存的测量数据。
- **保存与导出保护：**城市保存检查历史快照完整性，损坏时阻止覆盖；无变化草稿的失败重试不再误报成功；单栋文件写完并关闭后原子发布，下载核对 SHA-256。
- **GeoJSON 导入：**整批校验结构、坐标和多边形，畸形或自相交输入明确拒绝；几何转换及响应编码移入线程池，改善批量导入期间其他 API 的响应性。

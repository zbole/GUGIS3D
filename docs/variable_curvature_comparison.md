# 变曲率地形：把方向优势放到更严格的控制下

2026-10-06。本阶段将已公开的常曲率试验延伸到严格凸、局部 Hessian 随位置变化的四次曲面。协议先提交到 Git，再计算全部结果。网站入口：`/compare#variable-curvature-results`，位于“方向优势”的变曲率验证展开项内。

默认示例为强方向性曲面、30°、N=2,048：面带 E₂ 为 **0.09551514 m²**，论文式 P1 为 **0.26242994 m²**，降低 **63.60%**；完整 GPR3 文件为 **45,000 / 48,616 B**，面带小 **7.4%**。此时固定层级 P2 控制为 **0.01788949 m² / 46,440 B**，比面带更准确。网页直接显示该控制，避免将优于顶点 P1 插值解释成优于所有高阶三角方法。

## 对齐的方法与预算

每种曲面在同一 `[-50,50] × [-50,50] m` 物理方形内旋转，不改变计算面积。使用先前冻结的论文式 L₂ 贪心区域选择、L₁ 二分选边与三角带打包；既有四次曲面的 0° 每档预算与原论文复现实验逐值一致。没有添加 C⁰ 细分闭合，也没有执行作者原始程序。

面带采用沿曲线方向二次、跨带方向线性的 P₂×P₁ 函数。每例固定候选为三类方向、6 档曲线分段、10 档跨带分段，共 180 个；14 例合计 2,520 个。只排除无法满足任何固定预算的候选，其完整预测字节数和排除原因也在原始结果中。面带选择、世界坐标轴控制及 P2 控制分别在固定候选池中取最小全域 E₂，**同时满足当前 P1 的完整文件字节数和原生面数两项上限**。它们实际花费不必完全相等。

P2 使用固定 P1 二分层级上的六节点 Lagrange 插值，并在该层级的全部固定档位中选择；不是全局最优 P2 网格。方向来自解析全域平均 Hessian，不能保证它优于固定坐标轴，更不能推广为已经解决真实带噪 DTM 的方向估计。

## 已保存模型的独立核验

完整 GPR3 文件包含共同 48 B 裁剪头、Float64 XYZ 点池、面记录和索引。旋转后超出方形的全部控制点也计入文件。**2,071 个**实际模型全部保留。

生产计算使用五节点 Gauss–Duffy 求积；发布重新执行完整 P1 层级、重建所有合格候选，使用独立 Bernstein / 重心基函数和独立方形裁剪，在七节点求积下复算每个已保存模型。积分面积全部为 10,000 m²。E₂ 定义为 `√∫(z模型−z源)² dA`，单位 m²。

原生 TypeScript 解码并重新编码全部二进制文件，独立校对 **2,120,704 次**内部高程与梯度查询，以及每模型四个角点和两个越界点。审计中的抽样 RMS、最大差只作诊断，不作为积分误差或连续最大误差证明。网页展开原生查询后，才读取当前三个校验和绑定模型；关闭、切换和损坏重试均有测试。

这些是固定有限候选上的表示空间与方向适配结果。没有测量 CPU/GPU、内存、实测地面精度或 ArcGIS 软件性能，也不是新的 P1 最优性定理或区间算术证明。

# 真实 DTM 的规则二次面带控制

此控制回答一个具体问题：解析函数上的二次直纹面结构收益，能否直接推广到已有真实城市 DTM？结果尚不能支持该推广，网站将它放在查询优势结果后的可展开适用范围中。

使用十座城市已经冻结的全部 20 个 65 × 65 源像素窗口。每窗预先固定 98 种网格：横、纵两个方向，以及各方向 1、2、4、8、16、32、64 段的组合。三档预算来自同窗已保存的 10、25、50 cm 自适应 P1 三角带，双方使用相同精简 JSON 外壳，保留完整点池和原生面片。

60 个文件预算中，56 个能容纳面带候选，但没有一个获得更低的全域 E₂。没有候选同时满足 P1 的实际最大误差界和文件预算。全部候选、未适配预算、选中模型与原始源窗口均保留，未筛除不利结果。

P1 原有五位小数高程保留，面带使用未舍入的源 Float64 高程，因此 JSON 序列化精度也是本控制的限制。它比较有限的规则网格池，未证明最优面带的性能。二次面带误差逐原始像素格积分，并检查格内二次驻点；发布前另用五阶求积复核全部 1,960 个候选并重新积分全部 60 个 P1 文件。原生 TypeScript 内核对每个保存模型查询 512 个内部坐标，并核验面带的最大误差见证点。

参考面是原始 1 m DTM 的逐格连续双线性曲面，不是独立测量真值。这些 C₀ 栅格面不符合 arXiv:1101.1452 的严格凸 C² 假设。P1 采用既有最大误差优先细化，本控制既不是论文作者软件，也不是 ArcGIS 的软件运行。

数据发布在 `frontend/public/research/dem-curved-grid-v1/`：完整记录、60 组 CSV、原生查询审计、全部保存模型、科学图 SVG，以及含源码和源窗口的 ZIP。`shared/dem-curved-grid-control-v1.json` 与发布回执逐字节一致；回归检查绑定生产者、发布者、查询内核、源数据、图表及证据 ZIP 的 SHA-256。原始高程来源：Environment Agency 2022，OGL v3.0。

后续方向是按局部地形选择和组织函数面带，而不是把规则网格当成对所有地形都占优的算法。解析函数和同函数查询的已有正向结果继续单独展示，声明范围保持明确。

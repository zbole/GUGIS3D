# GUGIS3D 网站功能与工作流程

本页记录当前布里斯托起始街区网站的实际入口、数据状态和交付物，供后续开发与演示使用。对比展示中的数字是保存快照；工作台读取本地正式项目，二者修订号不一致时应按历史快照理解。

| 入口 | 主要任务 | 输入与操作 | 保存结果 |
| --- | --- | --- | --- |
| `/compare` 对比展示 | 展示 GUGIS3D 的项目证据、ArcGIS 官方功能对照和实验边界 | 选择三项对比主题，查看数字和来源，进入对应工作区 | 只读；不修改城市 |
| `/` 城市项目 | 浏览布里斯托建筑、道路、地形与地物，选择或筛选建筑 | 场景点击、列表搜索、导入城市/建筑、细化、复制、删除 | 新建、复制、细化和导入先生成独立草稿；删除写入正式项目并可从历史恢复 |
| `/?workspace=author` 制作 / 更新 | 通过参数生成建筑，选择位置，修改现有建筑，批量生成街区 | 参数表单、场景选址、生成 | 建筑与街区先进入独立草稿；确认后写入正式项目 |
| `/?workspace=environment` 地形 / 地物 | 导入或编辑原生地形，构造函数地物，观察地上与地下 | DEM/DTM、构造参数、图层与透明度控制 | 保存操作写入正式项目，并保留历史版本 |
| `/?workspace=analysis` 空间分析 | 路线剖面、联合剖面、空间查询和记录复算 | 场景选点、宽度与间距、结果列表 | 分析记录可保存到正式城市档案；临时选点本身不保存 |
| 楼栋详查 | 查看选中建筑的楼层、语义构件和结构 | 在城市项目选楼后进入 | 只读视图；可导出单栋对象 |

## 数据状态

1. **正式项目**是城市档案的当前修订。场景、分析与导出以它为可恢复的基准。
2. **独立草稿**用于建筑生成、复制、细化、批量街区与导入。生成后先检查场景，再确认写入正式项目或丢弃。草稿跨刷新恢复，不应把它误认为已经导出的正式城市。
3. **历史版本**用于恢复先前状态；恢复前可预览，恢复操作仍需确认。
4. **对比快照**是单独测得的证据数据。数据堆节省的参照是同城几何展开后的独立点线表示，不是 ArcGIS 内存测量。ArcGIS 同机性能比较仍待测。

## 本轮界面整理

- 工作台增加当前工作步骤和数据状态提示，明确哪些操作进入草稿，哪些直接保存到正式项目。
- 城市建筑列表默认只渲染 40 栋，搜索与筛选仍覆盖全部建筑，可逐批显示更多。建筑数量、匹配数与显示数分别标示；场景选中列表外的楼栋时提供直接查找入口。
- 对比案例增加直达城市、函数地物、建筑制作或空间分析的入口；工作区地址可刷新重开，切换工作区时地址同步更新。
- 联合剖面与点查询仅在对应分析界面计算，减少切换工作区时的无关计算。

# GUGIS 城市环境扩展：函数地物与原生地形

2026-09-14。当前实现是项目既有 GUGIS JSON 的扩展，并非尚未提供的原 C++ 二进制规范。含 environment 的城市以 City 1.2 归档；原有 City 1.0/1.1 建筑项目继续可读，保存时自动选择对应归档版本。

## 在网站中使用

顶部进入“地形 / 地物”。“地形”页可以创建明确标注为非实测的演示地形，或选择 GeoTIFF、ESRI ASCII Grid 导入真实 DTM。新地形仅生成直纹面带与三角带；旧三角扇档案可兼容读取并按原三角面转换。可显示原生面带边界和生成线，调整透明度，并点击查询高程、坡度、坡向与面带编号。

“函数地物”页提供路灯、拱门、弧形阳台、圆形广场。地物保留函数名称、半径、角度、厚度和组件局部位置；组件使用分类颜色。支持场景选址、整体比例与朝向、修改现有地物、移除及主动定位。添加不会主动移动三维相机。保存整个城市后，以上结构与参数可继续编辑。

组件颜色可在折叠项内调整，同类组件在该定义内同步着色。编辑共享地物时，修改后的定义独立保存，其他地物保持原样。“复制为新地物草稿”保留当前参数与基点，调整位置后添加；未改动的定义继续共享。外半径必须大于内半径，错误会直接显示在表单中。

函数地物页持续显示橙色基点，选址结束后仍保留，便于确认落点；保存、选择、复制均不自动移动三维相机。“定位此地物”位于已有地物选择框下。按 Esc 结束选址或查询。更换地形会恢复不透明显示并清除旧查询结果；取消 DEM 文件选择不会生成或替换地形。

“所属层”区分地上/地表与地下；距地形高度允许负值。降低地形不透明度可观察地下对象。这是地下对象定位与显示基础，还没有地层拓扑、钻孔、挖填体积或地下空间相交分析。

## 直纹面带的定义

按用户确认，两条边界曲线之间连续排列直纹面。本轮边界采用共享控制点构成的分段线性曲线。

一个相邻区段的四个点为 a=Lᵢ、b=Rᵢ、c=Lᵢ₊₁、d=Rᵢ₊₁，局部参数 u,v∈[0,1]：

```
L(u) = (1-u)a + uc
R(u) = (1-u)b + ud
S(u,v) = (1-v)L(u) + vR(u)
```

固定 u 时，v 方向是连接两条边界的直线；沿 u 连续排列形成直纹面。相邻区段共享边界控制点，保留位置连续性，不保证一阶导数连续。一般四角不共面，区段为双线性曲面，不能将查询简单替换成对角线两侧平面。

保存结构为 `{id, kind:"ruled-strip", left:[点索引], right:[点索引]}`。两侧索引数相等；前后相邻的对应点定义区段。不同面带共用 environment.terrain.points。

## 三角带与旧三角扇兼容

三角带保存 `{id, kind:"triangle-strip", indices:[…]}`。连续三个索引构成三角形，奇偶三角形交换绕序，保持朝上法向。

旧档案的三角扇保存 `{id, kind:"triangle-fan", hub:中心点索引, ring:[…]}`。ring 不重复首点，闭合由格式约定给出；每条辐射三角形为 hub、ring[i]、ring[i+1]。当前地形构造器不再生成三角扇；兼容转换把每个扇拆成至多三个三角面一组的短三角带，保留控制点与全部原三角面。三角扇在未来洞口等非单值高程场场景再独立设计。

直纹面带与三角带共同使用共享点表；兼容读取的旧三角扇也沿用此点表。校验索引、绕序、退化面、重复边和非流形边，直纹面要求凸且不折叠的水平投影。查询器按 64 m 网格索引检索候选区段；直纹面反求 u,v 后使用 S 求高程和导数，三角区域采用重心坐标和平面导数。NoData 空洞和范围外返回未命中，不外推。

这里的地形是单值高程场，不支持悬垂岩体、多层洞穴或垂直断面作为同一高程场。坡向以局部 ENU 北方向为起点顺时针计算，平地无坡向；边界处采用命中一侧的导数。

## DEM 转换与误差口径

导入接受单波段、北向上、非旋转的 GeoTIFF / ESRI ASCII Grid。读取文件坐标系，或明确指定 EPSG:27700 / EPSG:4326。裁剪范围为经度 -2.614 至 -2.592、纬度 51.446 至 51.462，覆盖当前布里斯托起始街区及周边。

ASCII 栅格正确按像元中心取坐标，并将北到南的存储行序转换为南到北。GeoTIFF 应用波段 scale / offset。源高程以米解释，记录 ODN、椭球高、局部或未知基准；水平坐标转换为以 (-2.603,51.454) 为原点的 ENU 水平坐标。保存坐标与高程保留五位小数。

输入最多 128 MiB，输出最多 300,000 个有效控制点。采样步长 1 保持原像元密度，较大步长执行 nearest 重采样，可能丢失细节。NoData 相邻的不能完整构面的单元留空。当前分类按局部 2×2 单元块进行：最大相邻坡度比不超过 0.15 使用直纹面带，其余采用三角带。这是工程默认阈值，不是经实测校准的最优分区规则。

高度显示采用 `源高程 − reference_height`，reference_height 为有效样本中位数。ODN 高程不会直接假装成 WGS84 椭球高；当前未做垂直基准转换。建筑以基点采样高程整体平移，保持原模型刚体结构，未生成适应坡地的基础工程模型；DEM 未覆盖时保留原高度。道路显示沿地形采样，原始道路线仍保存在城市数据中。

显示时才将函数与曲面离散为 WebGL 三角形。直纹面通常以每区段 2×2 子网格显示，控制点超过 50,000 时用 1×1；查询仍使用原生曲面。显示面、重采样结果与原始全分辨率 DEM 的误差尚未完成实测误差界限验证，不能将采样间距当作实际精度。

## 函数地物格式

`environment.feature_assets` 保存共享地物定义，每个定义含若干组件。组件含 id、category、function、parameters、position、color。`environment.features` 保存定义引用、名称、WGS84 基点、距地形高度、朝向、比例和所属层。

支持 sphere（半径）、cylinder（半径、高度）、annular-prism（内/外半径、角度、高度）、arch-prism（内/外半径、厚度）、box（宽、深、高）。圆柱沿局部 Z 轴，以原点居中；圆环扇体在 XY 平面，角度以 +X 轴对称展开；半圆拱在 XZ 平面，以 +Z 为拱顶方向；组件位置叠加到这些函数局部坐标。地物朝向为绕局部 Z 轴的顺时针角度，整体比例同样作用于组件偏移。函数是封闭白名单，不执行任意字符串表达式。

路灯示例组合底座小柱、灯柱、连接件及球形灯罩；弧形阳台组合扇形板、弧形栏板和扶手。每个部件独立可编辑，修改部件尺寸不会自动调整其他部件，需要同时编辑局部位置。当前函数地物是独立城市对象，尚未建立与既有楼栋的宿主附着关系。

## 验证与下一步

已验证双线性鞍面的高程与解析梯度（中心高程与三角近似不同）、倾斜边界反求、三类曲面查询、函数离散几何闭合与朝外绕序、DEM 像元中心及 NoData、City 1.2 保存/导出/重载，以及拒绝把新环境写成 1.1 归档。原有建筑与道路数据保持不变。

当前本地演示地形将旧的 17 个三角扇转为 51 条短三角带后，含 2,809 个控制点、1,248 条直纹面带、121 条三角带，原生拓扑需 8,146 个 Uint32 索引。同一控制网的独立三角形需 16,224 个索引，索引容量减少约 49.8%。扇转带本身增加了索引；不能泛称三角带必然比三角扇紧凑。此比较不含点坐标、语义、对象开销及显示缓存，也不能当作 ArcGIS 性能结论。

本轮浏览器控制工具因运行资产路径错误无法初始化，尚未完成真实浏览器点击和视觉验收。下一步接入真实 Bristol DTM，固定空间范围、误差容差和查询工作负载，对原始栅格、TIN、带/扇表达分别测量最大/RMSE 误差、存储、保留内存、构建时间与查询耗时。创新与效率结论应以这些可复现结果及理论论证为依据。

2026-09-14 后续检查：33 项前端测试、38 项后端测试与生产构建通过。新增 React 组件状态和 Cesium 对象生命周期测试，覆盖 DEM 取消、参数校验、颜色写时复制、撤销同步、基点高度、相机保持及独立场景对象清理。测试使用真实 Cesium 数学/几何类型与替代的 Viewer/Primitive，不启动浏览器或 GPU，不能替代 WebGL 画面验收。通过正在运行的 Vite 代理执行整城导出、前端编码、后端校验互读，当前文件 SHA-256 保持 d46df2b59331dcafab9a9d751074b531c89dfcb1df89c6d0c1367e04b8da1ff9。

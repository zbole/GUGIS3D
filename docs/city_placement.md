# 建筑选址与视角保留

点击“添加建筑”，默认以当前城市场景的视图中心作为建筑基点。橙色标记预览该位置；可点击“在场景中选位置”后在场景地面选址，也可以输入经纬度。切换建筑类型不会改变已选坐标与朝向。标记仅表示基点，不表示建筑占地边界，请选择足够大的空地。

添加、更新或导入先生成独立草稿，在原城市场景预览；确认后才写入正式城市，可丢弃并恢复原数据。城市数据更新不重置三维相机，也不自动打开楼栋详查。新增对象显示在列表首位，并显示名称、位置标记及主动定位按钮。刷新可恢复草稿，历史版本也可先预览再恢复，详见 drafts_functions.md。

窄窗口下，进入场景选址或完成添加时会把页面滚动回场景区域，这不会改变三维相机。完整内部结构仍可通过“查看实体与楼层”主动打开。

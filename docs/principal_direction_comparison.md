# 主曲率方向面带：完整旋转对照

本轮新增可以旋转的二次直纹面模型和原生查询内核，使面带沿主要曲率方向组织，而不只沿世界坐标轴排列。对比页以该方向适配结果开场，保留同函数结构、查询效率、论文式 P1 复现和真实 DTM 适用范围。

固定七个方向（0、15、30、45、60、75、90°），曲率比为 100:1，物理范围为同一 100 × 100 m 方形。各方向均检查 36 个固定候选，九档 P1 面数预算组成完整 63 组对照。选择面带时同时限制原生面数和完整 P1 二进制文件字节数；超出方形的旋转控制点及裁剪信息全部计入文件。

63 组面带全域 E₂ 均低于论文式 P1 基线。在 N = 2,048 时，七个方向的 E₂ 减少约 99.88%–99.94%，完整文件减少约 39.4%–43.2%。30° 默认示例为 256 个面带、27,768 B；P1 为 2,048 个三角面、48,712 B。方向与世界坐标轴重合时没有额外方向收益；最小预算的文件代价可能相同，均保留在完整表中。

此优势来自高阶函数表达和曲率方向组织，不是更优的 P1 二分算法。强制纳入的高阶控制也公开：每个全局二次曲面只需两个 P2 Lagrange 三角形、九个共享节点、336 B 的同格式完整文件即可精确表示（实数算术），Float64 全域 E₂ 小于 10⁻⁸ m²。因此不能据本试验声称优于通用 P2 三角方法。

完整 GPR3 采用共同的 48 B 头部、Float64 XYZ 点池和 12 B 面片记录。新增协议独立于已冻结的 v1/v2，原有 GUGIS 城市和地形档案未修改。内核提供旋转平行四边形上的原生高程和笛卡尔梯度，同时支持 P1 三角带和 P2 三角函数。查询统一到同一个裁剪方形，越界返回无覆盖。

发布前重新生成全部 252 个候选，使用五阶求积复核裁剪后的全域误差，重新积分全部 63 个保存的 P1 三角带，并保留七个 P2 高阶控制。独立 TypeScript 审计对 174 个原生 JSON / 二进制模型执行 712,704 次内部查询，另验证覆盖角点、越界行为和面带最大误差见证点。所有文件、源码、图表和证据包绑定 SHA-256。

这是严格凸解析二次地形的有限试验。主方向来自精确的常数 Hessian，未验证噪声 DTM 的方向估计或变曲率地形。P1 使用论文式 L₂ 贪心、L₁ 选边和原有三角带打包，未添加一致细化闭合。未运行论文作者的原始软件或 ArcGIS 软件，也未测量 CPU 耗时、GPU 帧率、运行内存或证明新的渐近定理。

证据目录为 `frontend/public/research/principal-ruled-v1/`，包括全部 63 组 CSV、完整候选记录、原生审计、父试验记录、保存模型、科学图 SVG 和含源码的 ZIP。数值、源文件和页面回归均提供测试。当前受限沙箱中的浏览器工具启动失败，因此这一轮新增界面的真实浏览器截图验收仍待恢复；已有页面的前轮截图不冒充本轮截图。

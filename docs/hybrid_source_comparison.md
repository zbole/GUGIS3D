# 真实 DTM 的直纹面带与三角带混合表达

## 双对角线强控制

最新入口：`/compare#diagonal-hybrid-results`。原版固定单对角线对照仍保留在后文；首页当前使用更强的新基线：同一矩形单元的 P1 可在两条对角线之间择优，混合可在直纹面、两条三角对角线共三类单元之间择优。选择依赖原始源函数的局部 L₂ 平方误差，方向分组、重复边界索引和每个记录的字节都实际计入完整文件。沿共享边界仍为相同的线性函数，保持 C⁰；梯度可以跳变。

同原始 20 个 Float32 源窗口，每个 49 个预先固定张量网格，新方法共保存 **1,960 个模型**。在 **8,192 B 完整文件上限**下，全部 **20/20** 个样区的三类混合 E₂ 更低，降幅 **0.0036%–1.4219%**。全部十档预算为 **156/200** 组更低，余下结果和六档最大源函数误差目标中未达标的模型都保留。这里是相同文件上限，所选模型的实际字节数可以不同，不能表述为相同实际文件大小。

默认曼彻斯特中心中，双对角线 P1 完整文件为 6,036 B，三类混合为 6,136 B，E₂ 降低约 0.07784%。文件稍大但都满足上限。这个结果也表明，基线变强后收益会缩小；原先相对固定单对角线 P1 的 3.01%–18.09% 不应用于新基线。

三类选择允许 64 倍浮点 epsilon 范围内的数值平局，依次优先直纹、原负向对角线、正向对角线。在全分辨率 1 m 源单元上，两条 P1 对角线的局部平方误差完全相等，采用解析值与固定方向，防止浮点噪声制造额外方向记录。协议和实现在完整结果计算前固定；全部源数据及较弱旧基线未修改。

页面提供五种方法的实际字节、全域 E₂、连续最大源函数参考界、十档预算曲线和 20 样区完整结果。展开原生示例后，真实文件中的单元类型与对角线以绿色、蓝色、铜色显示；同一组 289 个内部坐标查询以共同色标显示误差，点击或坐标滑块同步查询保存函数。源栅格和模型均验证 SHA-256、尺寸、坐标、网格布局和单元覆盖，切换参数取消旧请求。展示点不能替代连续全域误差核验。

全部保存模型通过原生内核 **10,288,040 次查询**及 **8,534,400 对接缝高程**核验，独立五节点积分检查实际保存的角点系数、两条斜对角线和残差极值。前端与 Python 检查确认原源文件、完整候选、缺失结果、CSV、ZIP 和实现指纹。公开目录为 `frontend/public/research/diagonal-hybrid-v1/`；结果 SHA-256 为 `6a46d03e3ac044fac59d6713215eea3a0fc3ebe36d4408bcf131217575c17c4b`。完整 ZIP 为 40,690,425 B，SHA-256 为 `d01b95ef7c2665187332a9867d2bd60a446e119e8145fcc4fb87cfb4e6faa3a8`，其中保留原始较弱对照的完整证据 ZIP。

这仍是固定张量网格相对源函数的近似误差，不是论文自适应剖分算法、实测地面精度或 ArcGIS 软件性能。科学图与原生示例已渲染核对，浏览器控制内核仍不可用，未报告真实浏览器/GPU 验收。GitHub 网络连接失败，新提交暂保留本地。

## 原版固定单对角线对照

入口：`/compare#hybrid-source-results`。输入来自已经公开的十城二十固定样区，每个样区含 65 × 65 个原始一米 Float32 节点，比较的是节点之间 64 × 64 m 的源双线性高程函数。

在完整文件不超过 **8,192 B** 的条件下，混合表达在 **20/20** 个样区中的全域 E₂ 都低于本次固定网格 P1，降幅 **3.01%–18.09%**。全部十档预算共 **179/200** 组优于 P1；其他结果同样公开。这里的 P1 是固定张量网格三角带，不能将这一结果描述成打败论文的自适应算法。

## 连接与误差

每个样区检查 49 个固定张量网格、三种表示，共 2,940 份原生模型。每个矩形单元可用共享角点的双线性直纹面，或者两个 P1 三角面表示。混合方法按全域积分中的局部平方误差选择类型，连续同类单元合并为面带或三角带记录；额外记录和重复边界索引全部计入完整 GPR4 二进制文件。

所有单元共享整数网格角点，两种类型沿矩形边界具有相同的线性函数，因此保持 C⁰，梯度可以跳变。这里没有独立细分引起的 T 形接点。

E₂ = √∫(z模型 − z源)² dA，单位 m²。面带与源函数在一米源单元内的残差为双线性函数，最大绝对差检查角点；三角模型还检查裁切后的对角线二次残差极值。只检查源节点会漏掉对角线内部峰值。连续最大差包含明确的 Float64 数值余量，不是严格区间证明，也不是实测地面精度。

页面支持二十样区、十档完整文件预算和六档最大差目标。原生查询按需读取当前三种模型和原始源高程格，检查长度、SHA-256、坐标原点和网格布局，再由原生函数返回同点高程、坡度和源函数差。17 × 17 线框只是显示采样，另图直接显示保存文件中的混合类型分布。

界面使用由完整不可变报告派生的紧凑视图，仅保留实际显示的指标和下载回执；所有样区、预算、未合格项与数值保持一致。`python data-pipeline/build_hybrid_ui_summary.py --check` 可逐字节检查该视图，公开研究报告不受裁剪。

新增同尺度误差热图：三种模型在同样的 289 个内部点分别查询真实源函数差，共用统一色阶（最低 ±1 mm）；蓝色较低，白色接近源值，橙色较高。点击色块同步所有模型的查询点，上方滑条仍支持键盘。位置取到小数点后两位，避免只采源节点而隐藏 P1 的内部误差。热图是展示采样，不作为全域积分或连续最大差的替代。

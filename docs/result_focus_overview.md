# 以结果为主的三条对比主线

对比页首屏入口：`/compare#validated-advantages`。它优先展示三个独立问题，把文件格式的两项收益放在次要信息区。固定研究输入不随当前城市切换，避免将研究样例当作任意城市的当前测量。

1. **论文式 P1 精度**：强方向性四次曲面、30°、N=2,048，GUGIS 面带 E₂ 为 0.095515 m²，论文式 P1 为 0.262430 m²，降低 **63.60%**。同类七角度九预算 **63/63** 组更低，降幅 33.81%–90.16%。当前 P₂ 控制为 0.017889 m²，更准确；另一四次曲面仅 31/63 组有收益。这是论文算法指标与条件下的本项目复现，未运行作者软件。
2. **真实 DTM 混合**：十城二十样区、完整文件不超过 8,192 B，混合 E₂ 在 **20/20** 个样区比本次固定网格 P1 更低，降幅 3.01%–18.09%。迷你图保留全部二十个观察。共享边界保持 C⁰，混合记录开销计入文件；这是固定网格比较，与论文贪心算法分开。
3. **独立 CPU 复测**：五个同函数样例、三次新进程，**15/15** 个耗时中位数对比有面带收益，完整范围 1.024–1.408×。图中保留五例全部实测范围，完整 660 行原始记录可下载。范围不是置信区间，结果仅是本机 CPU 查询。

另外两项保留 **80.5%** 的同函数矢量文件收益，以及 **32.6%** 的实际 ArcGIS 兼容同几何文件收益。规则栅格、GeoTIFF 更小的控制结果也保留；ArcGIS 软件的同机加载、帧率及内存仍待测。

首屏清单仅 12,847 B，由七份不可变来源汇总及实际 ZIP 推导，包含来源 SHA-256。`python data-pipeline/build_result_focus.py --check` 可核验全部主结果、控制、完整文件回执和可下载证据。完整旧清单保持不变，新首屏无需读取原生模型或城市 API。

新结果的链接分别进入变曲率、真实混合和 CPU 复测详情。主结果片段不会误打开补充研究包，避免点击真实混合结果时加载无关的旧实验。详细数值、较差结果和复算下载位于对应证据内。

当前验证包括派生报告逐字节校对、React 信息与导航测试、TypeScript 和生产构建。没有将科学图 PNG 的渲染检查当作新增页面的真实浏览器或 GPU 验收。

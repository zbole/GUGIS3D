# 城市入口与有界渲染 · 2026-10-03

## 先选城市，再载入模型

访问 `/` 先显示城市选择页，可单选或多选布里斯托、伦敦、伯明翰。入口只请求城市目录，不预取三个城市档案或创建三个 WebGL 场景。多选是一个可切换的工作区集合；当前仍同时只保留一个城市场景，不把三个完整城市拼在同一显存中。

- 单选时只打开选中的工作区；多选后顶部下拉菜单只包含已选城市
- 可在进入前勾选“轻量分块浏览（只读）”，不先加载完整编辑档案；顶部也可在只读分块和完整编辑之间切换
- 只读网络加载可取消，不会锁住城市切换；完整编辑正在写入时仍禁止切换，已保存草稿保留
- “重新选择城市”会说明未生成表单、未保存分析和视角不会保留；已保存城市与独立草稿留在原城市
- 离开编辑器或返回选择页使用页面内确认：默认聚焦“留在当前工作区”，Escape 可取消；确认时重新核验写入锁，历史导航会撤销过时确认
- 只读页面可直接切换均衡 / 低资源读取配置；合法相机位置与来源修订经验证后恢复，选择和手动暂停重置，地址栏保存明确选择的配置
- 窄窗口先显示三维画面再显示建筑查询，提供“查看三维画面”快捷滚动；来源与分享说明可展开，缺失图层和质量提示仍在摘要中显示
- 写入进行中不能切换、退出或通过 Back/Forward 跳入另一城市；过时工作区回调不能锁住新城市
- 已有 `/?city=london`、`/?city=birmingham` 和工作区深链接仍有效。显式的 `?cities=london,birmingham&city=london` 可恢复多选集合
- `/compare` 仍是对比入口；不会把布里斯托的报告当作伦敦或伯明翰的测量

登记数量不是英国城市覆盖率。三个数据集都是局部样区；来源范围与遗漏说明仍见[三城工作区](multi_city_workspaces.md)。

## 视域内建筑的 GPU 常驻预算

此前远景仍为每栋建筑建立粗模 `GeometryInstance`。现在先根据相机视域及距离选择常驻建筑，再惰性分配共享几何；视角更新复用未改变的批次。

| 层级 | 预算 |
|---|---|
| 粗模建筑 | 800 栋 |
| 粗模构件实例 | 12,000 个 |
| 稳定批次 | 每批至多 128 栋，正常最多 7 批 |
| 细节建筑 | 48 栋 |
| 细节构件实例 | 16,000 个 |

选中建筑会保留，即使在当前视域外；超过细节预算时保留其真实粗模/完整后备几何，而不是截断模型。唯一明确例外：若选中的后备模型自身超过 12,000 个构件，只完整保留该选中模型，不将作者几何悄悄截短。该例外意味着粗模构件预算不是恶意或极端模型的绝对内存保护。

相机稳定后更新，10% 距离滞回减少临界位置来回装卸。相同视图不重建未变化批次。事件监听器、定时器、图元与材质沿原场景生命周期释放；选中对象、地形透明、空 overview 的正确后备行为保留。

## 可复现的分配计数

下面通过 Cesium 替代对象的生命周期测试统计实际 `GeometryInstance` 分配，不是浏览器 FPS、GPU 显存测量或 ArcGIS 对比。真实种子保持其原数据；合成 5,000 栋仅是负载测试夹具。

| 输入 | 原粗模构件 | 新粗模构件 | 常驻建筑 |
|---|---:|---:|---:|
| Bristol 仓库种子 | 10,435 | 10,435 | 615 / 615 |
| London 仓库种子 | 823 | 800 | 800 / 823 |
| Birmingham 仓库种子 | 809 | 800 | 800 / 809 |
| 合成 5,000 栋夹具 | 5,000 | 800 | 800 / 5,000 |

最后一行的粗模分配减少 84%；不能推断帧率提升 84%。小场景视域内数据保持完整，平移/缩放后按预算装卸，选中目标优先。

完整编辑模式仍读取完整城市档案，保留道路、地形和分析。新增可选“轻量分块浏览（只读）”只请求视域附近的建筑渲染包，限制并发、驻留字节和缓存并淘汰旧瓦片，不读取正式城市或草稿。该模式明确缺少道路、地形及完整语义；预先构建缓存后使用。详见[分块渲染与客户端验证](render_tiles.md)。编辑文档 3,000 资产 / 5,000 实例限制没有粗暴提高，也没有宣称全英国数据已接入。

## 已知源数据质量

旧种子存在已识别的高度和竖向语义问题，不能因修复导入器就宣称旧种子已修正。城市目录给出文件修订号与对应审计警告；工作区只在警告的修订号与实际加载的正式城市一致时展示，草稿或后续修改不会继承该种子的断言。详见[来源复核与候选版本](city_source_validation.md)。

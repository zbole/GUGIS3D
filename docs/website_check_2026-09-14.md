# 网站检查与交互优化 · 2026-09-14

本地地址：http://127.0.0.1:5173/ 。这轮优化保留当前项目文件中的 616 栋建筑、544 条道路、7 个函数地物与 2,809 个地形控制点。

## 修复与优化

- 取消 DEM 选择不再进入创建演示地形的分支，避免意外替换已有地形。
- 修改函数地物时保留建筑、道路和地形；选择地物仅更新标记，不再创建整批地物几何。每种组件只生成一次离散几何缓存供实例使用。
- 建筑、地形线框、地物标记分别清理自己创建的场景对象，防止建筑更新误删其他图层。
- 函数地物基点在完成选址后继续显示，并始终按地形高度定位，不受“建筑随地形抬升”开关影响。
- 点击地形不会被误识别为建筑编号；添加、修改与选择保留相机视角，定位按钮由用户主动操作。
- 组件支持颜色编辑、尺寸联合校验与复制为新草稿；共享定义采用写时复制，未修改的副本继续复用原定义。
- 撤销或重新载入同一 ID 的地物后，表单同步恢复参数。按 Esc 结束选址/查询，更换地形清除旧查询并恢复可见状态。
- 记忆化地形统计，避免每次输入参数都遍历地形；已齐全的函数示例再次选择时不重复保存整城文件。

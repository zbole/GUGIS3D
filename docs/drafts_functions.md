# 函数展示、建筑扩建与草稿恢复

## 在网站中查看函数

进入“地形 / 地物”。已有函数地物时默认打开函数地物页，顶部直接显示组件组合、数学函数、参数域和当前数值。选择另一地物或修改参数，说明同步更新。展开“查看写入 GUGIS 的函数定义”可检查实际保存的 function、parameters、position、color。

路灯、拱门、弧形阳台和广场使用解析函数及离散组件。三维显示使用临时三角网；城市文件保留原生函数参数。现有楼栋和新增建筑类型仍采用参数盒体与封闭网格构件，不能称为全部建筑均已函数化。

## 新增建筑与街区

“制作 / 更新”提供都铎式木构街屋、港区砖砌仓库、英式礼拜堂、钟楼市政厅四种新设计类型，可调整层数、比例与位置。它们具有不同的木构斜撑、凸出屋顶、内部柱梁、塔楼、柱廊、钟面等构件；不是具体布里斯托建筑的实测复制。组件沿用分类颜色。

“扩建英式街区”支持 12、24、48 栋草稿，组合乔治式、维多利亚式、都铎式街屋与仓库。48 栋复用 8 套楼栋定义，每套平均使用 6 次。街区中心可调整，生成后应在预览中检查与已有建筑的位置关系；当前未实现自动避让已有建筑或按真实地籍扩展。

城市列表现在默认显示全部建筑。此前默认只列地标，容易误认为只有少量楼栋。

## 正式城市与草稿

生成、更新、复制、建筑细化、文件导入和历史恢复先产生草稿。草稿显示在原城市场景，保留相机；顶部显示正式与草稿的建筑数、地形点数差异。

- “确认写入正式城市”：一次请求提交服务器已有草稿，无需再上传整份城市；同时校验正式版本与草稿版本。提交回执支持断线重试，上一版本自动保留。
- “丢弃草稿”：恢复显示正式城市，删除独立草稿；不修改正式数据文件。
- 修改生成参数后必须重新生成预览，防止确认的是旧几何。
- 刷新页面会恢复独立草稿及单栋制作的类型、层数、位置、更新模式。重新生成沿用同一实例编号。正式城市或草稿被另一窗口改动时拒绝覆盖；旧草稿需要丢弃后重新生成。
- 导入、街区和历史恢复草稿不会被单栋制作表单意外覆盖；需先确认或丢弃。独立草稿校验失败时仍可读取正式城市，损坏原文件会保留。
- “导出整个城市”始终导出正式版本。草稿确认后，再导出包含新建筑的城市文件。

正式城市保存在 `.local/city/current.gugis.json`；独立草稿保存在 `.local/city/pending-draft.json`。当前每个本地工作区有一个待提交草稿槽，不是多项目草稿库。函数地物面板的“保存”与 DEM 导入仍是显式保存操作；存在建筑/恢复草稿时这些写入操作暂停，以避免覆盖草稿基于的正式版本。

## 恢复已有数据

顶部“历史版本 / 恢复”可分页读取已保存快照，先预览选中的版本，再确认恢复。恢复前的正式城市仍留在历史中。

“仅恢复内置建筑（保留地形 / 地物）”将建筑恢复到内置的 615 栋，同时保留当前道路、地形、函数地物和城市元信息。适合清理试做的自定义建筑；同样先预览差异，确认后才执行。

“预览内置初始城市”则预览完整内置文件，包括其没有新增地形的状态。不要将两种恢复范围混淆。
